# Gestor de Tareas

Sistema web de gestión de tareas que permite **registrar, visualizar, filtrar y eliminar** tareas pendientes.
Cada tarea tiene un título, una descripción, una fecha y un estado (pendiente o completada).

> Proyecto académico desarrollado por etapas (sprints).

## Objetivo

Facilitar la organización personal mediante una interfaz sencilla para administrar tareas.
